# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting:
**Security → Report a vulnerability** on this repository. Include what an
attacker can do, and how to reproduce it.

You will get an answer within a week. Fixes are released as soon as they are
ready, and credited to you unless you prefer otherwise.

## Supported versions

The latest release. Older releases get no fixes; [updating](docs/production.md#14-updating)
is a `git checkout` and a rebuild.

## Scope

The code in this repository and the deployment it documents. How szamlazo
is secured, and the audit of each release, are in
[docs/security.md](docs/security.md).
